# 🎭 Face Blur Remote

טשטוש פרצופים בווידאו. **העיבוד רץ על ה-iMac בווי-וורק, והשליטה מהטלפון, מכל מקום בעולם.**

```
 📱 טלפון בחו"ל  ──Tailscale (רשת פרטית מוצפנת)──▶  🖥️ iMac בווי-וורק
   מעלה סרטון / בוחר קובץ מה-iMac                      מזהה פרצופים, מטשטש
   בוחר פרצופים                                         שומר ב-~/FaceBlur/Outputs
   מקבל את הסרטון המוכן  ◀──────────────────────────
```

- **אין צורך לפתוח פורטים ברשת של ווי-וורק** (וזה גם לא אפשרי שם). Tailscale עובד דרך כל רשת.
- **רק המכשירים שלך** יכולים להגיע לשרת, ויש גם סיסמה.
- **אפשר לסגור את הטלפון** אחרי ההעלאה. העיבוד ממשיך על ה-iMac, ובכניסה הבאה לאפליקציה הסרטון מחכה.
- **העלאה עמידה לחיבור גרוע:** אם ה-Wi-Fi במלון נופל, ההעלאה ממשיכה מהנקודה שבה נעצרה.
- **אפשר לעבד קבצים שכבר נמצאים על ה-iMac** (תיקיית `~/FaceBlur/Inbox`) בלי להעלות כלום מהטלפון.

---

## 1. התקנה על ה-iMac (פעם אחת, כ-10 דקות)

פתח **Terminal** והרץ:

```bash
cd ~
git clone https://github.com/hafakot117/face-blur-video.git
cd face-blur-video
./mac/install.sh
```

> אם הפרויקט כבר קיים על ה-iMac: `cd ~/face-blur-video && git pull && ./mac/install.sh`
>
> ⚠️ שים את התיקייה **בתיקיית הבית** (`~/face-blur-video`) ולא ב-Desktop, ב-Documents או ב-Downloads. macOS חוסם שירותי רקע בתיקיות האלה.

ההתקנה:
1. מתקינה את כל מה שצריך (Python, OpenCV, ffmpeg מגיע מובנה, אין צורך ב-Homebrew).
2. מבקשת ממך **לבחור סיסמה** לכניסה מהטלפון.
3. מגדירה שירות רקע שעולה לבד בכל כניסה ל-Mac ומתאושש לבד אם קורס.
4. מציעה להגדיר שה-iMac **לא יירדם אף פעם ויידלק לבד אחרי הפסקת חשמל**. מומלץ לענות `y`.
5. מגדירה את Tailscale (אם כבר מותקן) ומדפיסה את **הכתובת לטלפון**.

### Tailscale על ה-iMac
1. התקן את **Tailscale** מה-App Store (או מ-[tailscale.com/download/mac](https://tailscale.com/download/mac)).
2. פתח אותו והתחבר (למשל עם חשבון Google או Apple). **אותו חשבון ישמש בטלפון.**
3. בהגדרות של Tailscale: סמן **Launch at login**.
4. ב-Terminal הרץ `./mac/manage.sh tailscale`. בפעם הראשונה יופיע קישור להפעלת HTTPS. פתח אותו, אשר, וההגדרה תסתיים לבד.
5. **חשוב לנסיעה ארוכה:** ב-[login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines) ליד ה-iMac לחץ `⋯` ובחר **Disable key expiry**. אחרת אחרי כמה חודשים ה-iMac מתנתק מהרשת ואין דרך לחבר אותו מרחוק.

## 2. הגדרה בטלפון (פעם אחת)

1. התקן **Tailscale** מה-App Store והתחבר **לאותו חשבון**. אשר את הוספת ה-VPN.
2. פתח ב-Safari את הכתובת שההתקנה הדפיסה, משהו כמו `https://imac.tail1234.ts.net`.
   אפשר לראות אותה שוב על ה-iMac עם `./mac/manage.sh url`.
3. הכנס את הסיסמה.
4. לחץ על כפתור השיתוף ⬆️ ואז **"הוסף למסך הבית"**, ותקבל אייקון כמו של אפליקציה.

## 3. שימוש

1. **חדש** ← "העלאה מהטלפון" (מהגלריה) **או** "קובץ שכבר נמצא ב-iMac".
2. ה-iMac מנתח את הסרטון ומציג את הפרצופים שמצא.
3. מסמנים את הפרצופים לטשטוש, בוחרים סוג (רגיל / אובלי / מוזאיקה) ועוצמה, ולוחצים **טשטש**.
4. אפשר לסגור את הטלפון. המצב מופיע בלשונית **עבודות**.
5. כשמוכן: **"שמור לטלפון"** פותח את גיליון השיתוף, ושם בוחרים *שמור סרטון* לגלריה. **"הורד קובץ"** שומר לאפליקציית Files.
   הסרטון נשמר גם על ה-iMac ב-`~/FaceBlur/Outputs`.

אם אותו אדם מופיע ביותר מכרטיס אחד, סמן את כולם. הזיהוי מקבץ פרצופים לפי המיקום בפריים.

## ✈️ לפני שיוצאים לחו"ל: רשימת בדיקה

- [ ] **בדיקה אמיתית:** בטלפון כבה Wi-Fi (רק סלולרי), העלה סרטון קצר, טשטש, ושמור לגלריה.
- [ ] **Tailscale על ה-iMac:** מוגדר *Launch at login*, ו-*Disable key expiry* מסומן בקונסולה.
- [ ] **חשמל:** ענית `y` בהתקנה, או ב-System Settings ← Energy הפעלת *Prevent automatic sleeping* ו-*Start up automatically after a power failure*.
- [ ] **עדכוני macOS:** ב-System Settings ← General ← Software Update ← Automatic Updates כבה את *Install macOS updates*. עדכון אוטומטי מפעיל את ה-Mac מחדש.
- [ ] **הישאר מחובר למשתמש** ב-iMac. נעילת מסך זה בסדר (`Ctrl+Cmd+Q`), אבל **לא** להתנתק (Log Out). השירות רץ רק כשהמשתמש מחובר.
- [ ] **FileVault:** אם הוא פעיל, אחרי כל הפעלה מחדש ה-Mac מחכה לסיסמה במסך הפתיחה, ושום דבר לא יעלה עד שמישהו יקליד אותה פיזית. לכן חשוב לכבות את העדכונים האוטומטיים (סעיף קודם). כדאי גם שמישהו בווי-וורק יוכל לעזור במקרה חירום.
- [ ] **מקום בדיסק:** לפחות 50GB פנויים. רואים את זה בלשונית **iMac** באפליקציה.
- [ ] **שמור את הכתובת והסיסמה** במנהל הסיסמאות של הטלפון.

### גיבוי: שליטה מלאה ב-iMac מהטלפון
אם משהו נתקע ואתה רוצה לראות את המסך של ה-iMac:
1. ב-iMac: System Settings ← General ← Sharing ← הפעל **Screen Sharing**.
2. בטלפון (עם Tailscale מחובר): אפליקציית VNC כמו *RealVNC Viewer* או *Screens*, וחיבור לשם של ה-iMac מתוך אפליקציית Tailscale.
3. מתחברים עם שם המשתמש והסיסמה של ה-Mac. ודא שהסיסמה חזקה.

## ניהול (ב-Terminal על ה-iMac)

| פקודה | מה היא עושה |
|---|---|
| `./mac/manage.sh status` | האם השירות רץ, Tailscale, מקום בדיסק |
| `./mac/manage.sh logs` | לוג חי (יציאה: `Ctrl+C`) |
| `./mac/manage.sh restart` | הפעלה מחדש של השירות |
| `./mac/manage.sh password` | החלפת סיסמה (כל המכשירים יתבקשו להתחבר מחדש) |
| `./mac/manage.sh url` | הכתובת לטלפון |
| `./mac/manage.sh tailscale` | הגדרת Tailscale מחדש |
| `./mac/manage.sh update` | משיכת גרסה חדשה מ-GitHub והפעלה מחדש |
| `./mac/manage.sh uninstall` | הסרת השירות (הסרטונים נשארים) |

האפליקציה `Face Blur.app` פותחת את הממשק בדפדפן של ה-iMac עצמו.

### תיקיות
| תיקייה | תוכן |
|---|---|
| `~/FaceBlur/Inbox` | שים כאן סרטונים כדי לעבד אותם מהטלפון בלי להעלות |
| `~/FaceBlur/Outputs` | הסרטונים המטושטשים |
| `~/FaceBlur/jobs` | קבצי עבודה זמניים. נמחקים אוטומטית אחרי 14 יום |
| `~/FaceBlur/logs/server.log` | לוג |
| `~/FaceBlur/config.json` | הגדרות. אפשר להוסיף תיקיות נוספות לעיון: `"library_dirs": ["/Volumes/Media/Footage"]` |

> תיקייה בכונן חיצוני או ב-Documents תעבוד רק אם נותנים ל-Python הרשאת *Full Disk Access* (System Settings ← Privacy & Security).

## פתרון תקלות

| בעיה | מה לבדוק |
|---|---|
| "אין חיבור ל-iMac" | ה-VPN של Tailscale בטלפון דולק? בקונסולת Tailscale, מתי ה-iMac נראה לאחרונה (*Last seen*)? אם הוא לא מחובר, הוא כבוי, נרדם או הופעל מחדש. |
| השירות לא עולה | `./mac/manage.sh logs` |
| לא נמצאו פרצופים | הזיהוי (OpenCV Haar) מתקשה עם פרצופים קטנים מאוד, מטושטשים או בפרופיל חד. |
| ההעלאה איטית | סרטונים גדולים עדיף לשים מראש ב-`~/FaceBlur/Inbox`, או להעלות כשיש Wi-Fi טוב. |
| "שמור לטלפון" לא מופיע | פתח דרך כתובת ה-`https://…ts.net`, לא דרך כתובת IP. |

## אבטחה
- השרת מאזין **רק ל-127.0.0.1**, כך שמהרשת של ווי-וורק אי אפשר להגיע אליו בכלל. הגישה היא רק דרך Tailscale Serve (HTTPS, רק המכשירים בחשבון שלך).
- סיסמה (שמורה כ-hash), חיבור שנשמר 60 יום, חסימה אחרי ניסיונות כושלים, והגנת CSRF.
- `config.json` נשמר עם הרשאות לבעלים בלבד.

## למפתחים
```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
pytest -q                 # בדיקות מקצה לקצה
FACEBLUR_HOME=/tmp/fb python server.py   # שרת מקומי על http://127.0.0.1:8765
```
| קובץ | תפקיד |
|---|---|
| `server.py` | שרת Flask: התחברות, API, העלאה במנות |
| `jobs.py` | תור עבודות ברקע, נשמר לדיסק ומתחדש אחרי הפעלה מחדש |
| `face_tracker.py` | זיהוי, קיבוץ וטשטוש פרצופים (OpenCV + ffmpeg) |
| `static/` | ממשק הטלפון |
| `mac/` | התקנה וניהול על macOS (launchd + Tailscale) |
| `blur_app.py` | הגרסה המקומית הישנה. עדיין עובדת (`python blur_app.py`) |
